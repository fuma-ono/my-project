# カシカリ(貸し借り可視化アプリ)

**位置づけ**: `personal-side-projects/style-video-editor/`と同じく、オーナー個人の副業プロジェクト。会社(AI Company OS)の意思決定プロセス・凍結ルールの対象外。

## コンセプト

友達同士の「奢った/奢られた」「頼まれごとをやった/やってもらった」を記録し、誰が誰に何を貸しているかをグループで可視化するアプリ。お金だけでなく、送迎・荷物預かり等の"頼みごと"も対象にする点が、既存の割り勘アプリ(Splitwise等)との違い。詳細な検討経緯は会話ログ参照(壁打ちの結果、Setlogの「摩擦ゼロ+習慣化+友達との共同体験」という勝ちパターンを踏まえつつ、技術的難易度・法務リスクが最も低い案として選定)。

## 今回作ったもの: 動くプロトタイプ

Wizard of Oz検証ではなく、**実際に動作するプロトタイプ**を今日作って公開した。Claude Artifactsの「ライブドキュメント」機能(閲覧者の操作がそのままみんなに共有される)を使っており、専用サーバー・アカウント基盤・データベースを一切構築せずに、友達と今すぐ試せる状態になっている。

**アプリURL**: https://claude.ai/code/artifact/e6f8f8d8-6321-4b5e-9845-467ea3b85aef

ソースは `app/index.html`(単一HTMLファイル)。

### 機能

- メンバー登録(名前を追加するだけ)
- 貸し借りの記録(誰→誰、お金 or 頼みごと、内容、金額)
- 記録の精算済みマーク・削除
- 残っている貸し借りの自動集計(お金は相殺して純額表示、頼みごとは件数で表示)
- 全員が同じページを見るので、誰かが記録すると全員の画面に反映される

### 現時点の制約(検証段階として許容している範囲)

- グループ(ページ)は1つだけ。複数の友達グループを分けたい場合は、今はページを複製する運用になる
- 個人アカウント・ログインはない。URLを知っている人なら誰でも編集できる(小さな友達グループでの検証にはこれで十分)
- 通知機能はない(誰かが記録しても他のメンバーには自動で知らされない)
