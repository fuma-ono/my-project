### 色の検証(ブランド画像と同じ色相マスクの中央値、CIE76 ΔE。5未満=かなり近い / 5〜10=同じ色名に見える / 10超=やや別味)
| 部位 | ブランド画像 | 描画フレーム(PNG) | MP4 から取り出し | ΔE(PNG / MP4) |
|---|---|---|---|---|
| ぽこまる体 | #74CF85 | #79C87E | #78C77D | 4.1 / 4.2 |
| ぴぴ体 | #FDC02C | #FCC33D | #FAC23B | 5.1 / 5.0 |
| ふわり毛 | #A2CEFA | #9BC1DD | #9BC1DB | 9.7 / **10.7** |
| ふわり耳の内側 | #FD97B3 | #F69AA9 | #F599A8 | 7.1 / 7.2 |
- ふわりの毛は、青がやや暗く灰色寄りに出る(目標より彩度が低い)。要改善。
- ほっぺ・角・目などは今回の検証対象外(領域指定がずれて測れなかったため**未検証**)。
- 「レモンイエロー」の指定に対し、ブランド画像のぴぴは金色寄りの黄(#FDC02C)。**画像を優先**した。変更するなら config の `pipi_body` のみ。
- 色は View Transform=Standard で出力。ライティングは、見える空は青・照明用の光は中立の白にして色の濁りを抑えた。

## レンダリング時間(CPU 4コア・GPU なし・Cycles・16サンプル+OpenImageDenoise・1080×1920)
| 項目 | 値 |
|---|---|
| 1コマ(平均 / 中央値 / 最小〜最大) | 41.9秒 / 41.7秒 / 36.1〜52.6秒 |
| 描画したコマ数 | **96**(2コマ打ち。24fps へは同じ絵を2回表示して複製) |
| 描画の合計 | **4,022.7秒(約67分)** |
| 全192コマを描いた場合の見積もり | 約134分(平均×192。実測ではない) |
| 参考(別フレームで試験) | 32サンプルは 72.2秒/コマ。16サンプルは 39.7秒/コマ |
- 30秒版(720コマ)を毎コマ描くと約8.4時間、2コマ打ちでも約4.2時間かかる見込み(単純な比例計算)。**このままでは重い**。
- 時間の大半はサンプル数と解像度。EEVEE などの軽い方式は**未検証**。

## 画質の所見(静止フレームを実際に見て)
- 良い点: 3匹の色・シルエット・顔(大きな茶目+白ハイライト、ピンクのほっぺ)が揃っている。虹・丘・花畑・字幕は読める。16サンプル+デノイズでノイズは目立たない。
- **ブランド画像との差**: 毛足・ふわふわ質感はなく、ツルッとしたプラスチック/粘土風。ぽこまるの質感、ぴぴの翼、ふわりのウインクなどは未再現。簡略モデル。
- 欠点:
  - ふわりの耳が交差して見える時間がある(耳の回転の向きが内向き。修正が必要)。
  - 画面上部の約3割が空だけで、構図が下に寄っている。
  - 静止フレームでは口が小さく閉じて見えるコマが多い(音の切れ目に当たるため。開閉の幅は小さめ)。
  - 2コマ打ちのため動きは 12fps 相当で、やや間欠的になる。
  - 前景の花は丸みのある塊で、花らしさが弱い。

## 音声(技術検証用。音質の良し悪しは判断していない)
- 私は音を聴けない。確認できたのは次の客観値だけ。
  - ナレーション2文は n1: 0.70〜2.91秒、n2: 3.51〜5.68秒に配置されている。
  - 無音区間は 3.0〜3.5秒と 5.7〜6.8秒で、それ以外は音が出ている(RMS 0.08〜0.10)。
  - ミックスのピークは約 -3 dBFS、統合ラウドネス -20.8 LUFS(配信用の目安 -14〜-16 より小さめ)。
- 効果音(ポップ・チャイム・ボヨン)は numpy 合成で、**聴感は未確認**。
- 口パクは音声の音量から自動生成しているが、口形(あいうえお)の対応はしていない。
- Open JTalk の声は機械的な合成音であることが分かっている。幼児向けとしては要差し替え(`tts.provider`)。**VOICEVOX 経路は書いたが未検証**。
