# スタイル系統別AI動画編集アプリ(仮称: StyleCut)

**位置づけ**: これはオーナー個人の副業プロジェクトです。`docs/ai-company-os/`配下で運用されている「AI Company OS」(BGM/アプリ/note/モヤスカの4事業)とは別トラックであり、会社側の意思決定プロセス(AI経営パートナーの独立分析必須化、新規事業探索の凍結ルール等)の対象外として進めます。経営ダッシュボード・KPI・財務台帳(`docs/company-os/`, `docs/dashboard.md`)にも含めません。

経緯の記録は `docs/company-os/proposals/2026-08-20-style-video-editor-app.md` と `docs/company-os/decisions/2026-08-20-style-video-editor-app.json` に残してあります(会社としては非推奨・オーナー個人プロジェクトとして分離、という決定履歴)。

## コンセプト

ユーザーが自分の動画素材をアップロードし、「解説系」「Vlog系」「エンタメ系」等のスタイルタグを選ぶと、そのジャンルの編集パターン(カット割り・テロップ・BGM選定・テンポ)をAIが自動適用して動画を仕上げるアプリ。

**却下済みの当初案**: 実在の有名YouTuber名(HIKAKIN等)をプルダウンで選択する方式は、パブリシティ権・著作権・不正競争防止法上のリスクが極めて高いため不採用。匿名のスタイルタグ方式(本ドキュメントの前提)で進める。

## 現在のフェーズ: 検証前

いきなり本格開発はしません。壁打ちの結論として、差別化点(「AIが自動編集してくれる」)は CapCut / Vrew / Descript 等の既存機能と比べて弱いという指摘が出ており、**「スタイル再現の精度」そのものが価値の源泉になるかを検証してから**開発投資すべきです。詳細は `docs/validation-plan.md`。

## オーナー(あなた)にお願いしたいこと

副業として進める以上、以下は私だけでは決められない、または実行できない事項です。

1. **プロジェクト名/ブランド名の決定**(本ドキュメントでは仮称「StyleCut」を使用)
2. **学習データ方針の最終判断**: `docs/legal-policy.md`で提案する「実在クリエイターの動画は一切学習に使わない、自社制作/許諾済み素材のみでスタイルパターンを定義する」方針に同意するか
3. **検証(Wizard of Oz)への協力**: 実際にスタイル別の編集サンプルを人力で数本作り、知人やSNSで反応を見るテストが必要です。私はサンプル動画の「編集指示書(どうカットしどうテロップを入れるか)」までは作れますが、実際の動画編集・SNSでの反応収集はオーナー側の作業になります(または外部の編集者に依頼するか)
4. **予算感**: ゼロ予算で進めるか(検証フェーズは基本ゼロ予算で設計します)、ある程度の投資(クラウド処理費用、App Store/Google Playアカウント等)を今後見込むか

まずは `docs/legal-policy.md` と `docs/validation-plan.md` に目を通していただき、方針に同意いただけるかを教えてください。同意いただければ検証フェーズの具体的な編集指示書の作成に進みます。
