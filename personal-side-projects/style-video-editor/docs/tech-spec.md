# MVP技術構成案(検証通過後に着手)

検証(`docs/validation-plan.md`)でポジティブな反応が確認できてから着手する。現時点では設計メモ。

## 第一段階: ルールベースの自動編集エンジン(機械学習なし)

`docs/legal-policy.md`の方針に沿い、まずは人力で定義したスタイルルールをプログラムで機械的に適用する。特定個人のスタイルをAIに学習させるのではなく、「解説系スタイルのルールセット」をコードとして実装する。

### パイプライン構成(要素技術は既存OSS/ライブラリの組み合わせで実現可能)

1. **シーン/カット検出**: 無音区間・場面転換検出(例: PySceneDetect、ffmpeg silencedetect)
2. **音声認識・字幕生成**: 発話内容からテロップの元テキストを自動生成(Whisper等)
3. **テロップ配置**: スタイルルールに従い、強調語検出→デザイン適用(フォント・色・アニメーション)
4. **BGM/効果音マッチング**: スタイルルールに従った選曲・挿入タイミング(著作権フリー音源のみ使用。`bgm-pipeline/`で使っている自社生成音源も転用候補)
5. **書き出し**: ffmpegでレンダリング

### 既存社内資産との接点(会社事業ではないが、技術知見は参考にできる)

- `bgm-pipeline/`: 自社生成音源をBGM候補として利用できる可能性(著作権フリーなので相性が良い)
- `moyasuka/assemble_video.py`: 動画組み立てのffmpeg実装パターンが参考になる

ただし、これは技術知見の参照のみで、プロジェクト自体は会社事業から独立して管理する。
