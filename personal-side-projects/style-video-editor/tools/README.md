# tools/

「編集技術を学習するAI」の第一段階として動くコード。`docs/tech-spec.md`で書いたパイプラインの最初の1ステップ(カット割りの解析)を実装したもの。

## 現状できること

`analyze_style.py` — 参考動画を読み込み、カット(シーン)の境界を自動検出して、カットのリズム(平均ショット長・カット頻度・ばらつき等)を数値化した「スタイルプロファイル」JSONを出力する。

**これは「ディープラーニングでスタイルを学習するAI」ではない。** 動画解析によってカット割りパターンを数値ルールとして抽出するツール。`docs/legal-policy.md`の方針(実在クリエイター動画は学習に使わない、ルールベースから始める)に沿った実装。

### セットアップ

```bash
pip install -r requirements.txt
```

システムに`ffmpeg`コマンドが入っていなくても動作する(`opencv-python-headless`が動画デコードを内蔵)。

### 使い方

```bash
python3 analyze_style.py <動画ファイル> --style-name "解説系" --out profiles/explainer.json
```

### 動作確認済み

合成テスト動画(4色×異なる長さのカットで構成)で動作確認済み。実際のカット境界を検出し、平均ショット長・カット/分・ばらつきを正しく数値化することを確認した。

```
$ python3 analyze_style.py /tmp/test.mp4 --style-name test_synthetic --threshold 15
{
  "style_name": "test_synthetic",
  "cut_count": 3,
  "shot_length": {"mean_sec": 1.99, "median_sec": 2.46, ...},
  "cuts_per_minute": 30.21,
  ...
}
```

## 次にやること(あなたの動画が必要)

- 実際の参考動画(自作・許諾済みのもの)で試し、意味のあるスタイルプロファイルが出るか確認する
- テロップ検出(OCR)・BGM区間検出を追加する
- 複数の参考動画を束ねて「解説系スタイル」の平均的なプロファイルを作る(1本だけでなく複数本の平均を取ることで、個別動画のクセではなくジャンルの傾向を抽出する)
- 抽出したプロファイルを使って、別の動画に同じカットリズムを自動適用する`apply_style.py`(まだ未実装)を作る

## 制約

この開発環境には`ffmpeg`コマンド自体は入っていない(パッケージ取得エラーで導入不可だった)。`opencv-python-headless`はffmpegの機能を内蔵しているため動画の読み込み・解析はできるが、将来的にテロップ焼き込み・音声処理・書き出しを行う`apply_style.py`では改めてffmpeg(または同等のPythonライブラリ)が必要になる見込み。実際の開発・実行環境を用意する際は`ffmpeg`が入っていることを確認すること。
