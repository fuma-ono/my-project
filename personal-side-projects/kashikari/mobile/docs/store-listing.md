## 両ストア共通: 詳細な説明文

```
kashikariは、友達同士のお金・頼みごとの貸し借りを、揉めずに記録・精算するためのアプリです。

【できること】
・グループを作って、友達とお金の貸し借り・頼みごとを記録
・「支払った」→「受け取った」の2段階確認で、うやむやにせず精算
・複数人での割り勘も自動計算
・最小の支払い回数にまとめる「オート精算」
・レシート画像を添付して記録を残せる
・記録の変更・削除があれば通知でお知らせ、台帳でも一目で分かる
・Google/Apple/LINE/メールアドレスでかんたんログイン

グループ内はお互いを信頼する前提の設計です。誰でも記録の精算状態を変更・訂正できますが、その変更は必ず相手に通知され、台帳画面でも分かるようになっています。

「あれ、まだ返してもらってなかったっけ?」を無くす、友達とのお金の記録アプリです。
```
