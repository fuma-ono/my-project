## 方針

1. **フォロワー0の間は無料記事+サポート機能のみ。** サポート(投げ銭)機能は既に有効化済み。単発有料記事はいきなり売れない。
2. **コンテンツは2ジャンル体制で運用する**(2026-08-18〜)。ジャンルA: Focus & Sleep(睡眠・集中サウンド、既存)。ジャンルB: 恋愛ジャンル(新設、オーナー指定の作家が担当)。旧・柱B(個人開発・AI経営)は、実際の運用ではジャンルAの中で単発の透明性記事(値付けの裏側、売上¥0の報告等)として扱われていたため、独立ジャンルとしては廃止しジャンルAに統合する。
3. ある程度スキ/閲覧が集まった段階で、月額300〜500円の定期購読マガジンへ移行する。**Focus & Sleepジャンルはメンバーシップ企画を進行中**(`note-articles/membership-plan-focus-sleep.md`)。
4. 記事内で他事業(BGM動画・アプリ)への導線を張り、事業間を回遊させる。
5. トピックは「ノウハウの羅列」より「〇〇してみた失敗談・気づき型」を優先する。
6. **アフィリエイト(Amazonアソシエイト/楽天)を導入する。** 記事テーマに関連する商品のみ、記事末尾に自然な形でPR表記付きで掲載する。詳細は `docs/marketing/note-affiliate-guideline.md`。
7. **常に両ジャンル合計で6本の下書きをキープする。** 現状はジャンルAのみで6本(下記進捗参照)。ジャンルBが立ち上がり次第、両ジャンルのバランスを取る。
8. **週次アジャイルサイクルで回す。** 計画→公開→計測(スキ数・閲覧数)→振り返りを毎週繰り返す。
