## 方針

1. **フォロワー0の間は無料記事+サポート機能のみ。** 単発有料記事はいきなり売れない。
2. **コンテンツは2本柱で運用する**(2026-08-01〜、`docs/marketing/2026-08-note-sns-growth-strategy.md`)。柱A: BGM動画・アプリ事業と同じ世界観(睡眠・集中・作業用サウンド)のゆる記事。柱B: 個人開発・お金・AI経営の記事(このプロジェクト自体の実況、expense-appへの導線)。週1回更新を目標に、柱A/Bを交互に出して読者層を広げる。
3. ある程度スキ/閲覧が集まった段階(目安: 記事平均スキ数が二桁に乗る、フォロワーが増え始める)で、月額300〜500円の定期購読マガジンへ移行する。
4. 記事内で他事業(BGM動画・アプリ・expense-app)への導線を張り、事業間を回遊させる。
5. トピックは「ノウハウの羅列」より「〇〇してみた失敗談・気づき型」を優先する(`docs/marketing/2026-08-content-topics.md` の調査結果より、この型が最も読まれる)。
6. **アフィリエイト(Amazonアソシエイト/楽天)を今から導入する。** 記事テーマに関連する商品(イヤホン、アイマスク、ホワイトノイズマシン等)のみ、記事末尾に自然な形でPR表記付きで掲載する。詳細は `docs/marketing/note-affiliate-guideline.md`。
7. **SNS(X)で告知する。** 新しい記事を公開するたびにX投稿文をドラフトし、「SNS投稿キュー」ページにまとめる。オーナーはコピペで投稿するだけでよい運用にする。詳細は `docs/marketing/2026-08-note-sns-growth-strategy.md`。
8. **週次アジャイルサイクルで回す。** 計画→公開→計測(スキ数・閲覧数)→振り返りを毎週繰り返し、伸びた記事の型を次のネタ選定に反映する(ウォーターフォールではなく、実測フィードバックを反映できるアジャイルを採用)。
