# note1年目、スキがつかない日々で気づいた「ゆる記事」のリアル

このnoteを始めてから、まだ2週間ちょっとしか経っていない。「1年目」と言うにはおこがましいけど、フォロワー0・スキ数も片手で数えられる状態で記事を書き続ける感覚は、たぶん多くの人が最初に通る道だと思うので、正直に書いておく。

一番こたえるのは、公開した瞬間の「反応がまったくない」時間だ。書いている間は「これは需要があるはず」と思っているのに、公開して数時間経っても数字が動かないと、急に自信がなくなる。SNSで拡散されるわけでもなく、検索から来る人もまだいない。ただ静かに、記事だけがそこにある。

それでも記事を書き続けているのは、「スキがつくかどうか」と「書く価値があるかどうか」を、途中から分けて考えるようにしたからだ。スキは今のところほぼ運と露出の問題で、記事の中身の良し悪しとは別のところで決まる。だったら、スキがつかない前提で、自分たちが本当に伝えたいこと(睡眠や集中に悩んだ経験、AIに会社を任せてみた顛末)を淡々と積み上げる方が、精神衛生上もいいという結論になった。

もう1つ気づいたのは、「ゆる記事」でいいということ。最初は1本1本を渾身の力作にしようとしていたけど、それだと更新が続かない。むしろ「今週こう思った」くらいの軽さで書いた記事の方が、読み返しても自然だったりする。バズらせるための記事より、続けられる記事の方が、今のフォロワー0という段階では優先度が高い。

数字が動き出すのはまだ先だと思う。ただ、スキがつかない日々そのものを記録として残しておくのも、後で読み返したときに意味があるんじゃないかと思っている。
