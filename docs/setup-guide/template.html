アカウント作成ガイド

上から順番にやればOKです。名前・説明文などはそのままコピペで使える文面を用意しました。作り終わったら「完了」とだけ教えてください、続きを進めます。所要時間の目安トータル: 60〜90分(Apple/Googleの本人確認待ちは除く)。

始める前に用意するもの
  • 事業用に使うメールアドレス(まとめて管理したいなら新しいGmailを1つ作るのがおすすめ)
  • SMS認証を受けられる電話番号
  • クレジットカード(Apple Developer $99/年、Google Play Console $25の支払いに必要)
  • 本人確認書類(運転免許証・マイナンバーカードなど。Apple/Googleの登録で求められる場合があります)
🔒 各アカウント、作った直後にこれだけやってください
  • 二段階認証(2FA)をその場で有効化する(あとで、にすると忘れます)
  • 使い回しのパスワードを使わない。パスワードマネージャーで生成した固有のものを設定する
  • 復旧用のメールアドレス・電話番号を最新の状態にしておく(乗っ取り対策)
  • 特にApple Developer / Google Play Consoleはアカウント停止が即事業停止につながるので、ここだけは念入りに
1
Google アカウント(YouTube・Google Playで共用)
所要時間: 約5分
  1. accounts.google.com/signup を開く
  2. 「自分用」ではなく「ビジネスの管理」を選び、下のメールアドレス候補(空いている最初のもの)で登録
  3. 氏名は本名を入力(将来AdSense/Play Consoleの支払い設定で本人確認が必要になるため、後で変えずに済みます)
  4. 復旧用のメールアドレス・電話番号は、普段使っている個人のものを設定する(ここを新しいアドレス自身にしない。ロックアウト対策)
  5. SMSで届く確認コードを入力して完了

YouTube チャンネル作成
所要時間: 約5分
  1. 手順1のGoogleアカウントで youtube.com にログイン
  2. 右上のプロフィールアイコン →「チャンネルを作成」
  3. 「個人名」ではなく「カスタム名を使用」を選び、下のチャンネル名を入力(ブランドアカウントとして分離されます)
  4. 作成後、YouTube Studio →「設定」→「チャンネル」→「基本情報」の概要欄に下の説明文を貼り付け

3
Google Play Console(アプリ公開用)
所要時間: 約15分 + 本人確認待ち(最大48時間)・$25
  1. play.google.com/console/signup を開く(手順1のGoogleアカウントでログイン)
  2. アカウントの種類は「個人」を選択(法人化していないため。組織より審査が速い)
  3. 氏名・住所・電話番号を入力し、本人確認書類をアップロード
  4. 登録料 $25 をクレジットカードで支払う(一度きり)
アプリ名(登録時に使用)
Focus & Sleep Soundsクリックでコピー
これで完了。審査完了の連絡が来たら教えてください。アプリのビルド・ストア掲載情報の入力を進めます。
4
Apple Developer Program
所要時間: 約20分 + 審査待ち(数時間〜48時間)・$99/年
  1. Apple IDを持っていなければ appleid.apple.com で作成
  2. developer.apple.com/programs/enroll を開く
  3. 「個人(Individual)」で登録(組織登録はD-U-N-S番号が必要で時間がかかるため)
  4. 本人確認 → 年会費 $99 を支払う
Macは不要です。Expo(このアプリの開発基盤)のクラウドビルド(EAS Build)を使うので、Xcodeやmacがなくてもこちらでビルド・提出できます。承認されたら教えてください。
