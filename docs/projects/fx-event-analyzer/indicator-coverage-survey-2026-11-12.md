# 経済指標の未対応範囲の全量調査(2026-11-12)

HQ指示 2026-11-12「経済指標の未対応範囲の全量調査」。対象: 米国・日本・英国・ユーロ圏・豪州・カナダ・スイス。
調査のしかた: 公式の規約・公表予定のページを WebFetch で読み、引用できたものだけを「確認済み」とした。ページが 403/404 で読めなかったものは
**「未確認」**(「禁止」や「不可」という意味ではない)。推測で埋めていない。次回の日程などは、確認できたものだけ。

実装の状況の見方:
- **DEV に値あり** = DEV の DB にイベントと値が入っている(2026-11-12 の読み取り専用の確認)。
- **コードあり・DEV なし** = 取り込みのコードはあるが、DEV にイベントも値も無い(手動の target が無い、または未実行)。
- **指標マスターのみ** = 指標の行だけある。

## 4. 優先度の提案(承認をいただきたい順)

**A. すぐに進められる(無料・商用の条件が確認済み・追加のコストなし)**
1. 英国・豪州・カナダの**予定と値の取り込みを DEV で動かす**: 手動の target(`gb-au-ca-schedules`・`official-values` とその dry-run)を足す。コードは settings に入っていて、公式の値の読み取りは 11/12 に公式の発表ページと一致を確認済み(GB: CPI 3.5・コア 2.8・失業率 4.7、AU: CPI 4.3・失業率 4.7、CA: 失業率)。
2. 米国 JOLTS の 2027-10 分までの予定を DEV に反映(既存の手動の target `official-bls`)。
