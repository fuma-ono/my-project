## 1. CA_CPI(カナダ消費者物価指数)の取得元

### 確認済み(2026-11-13 に本物の応答で確認)
| 項目 | 内容 |
|---|---|
| 公式情報源 | Statistics Canada(統計局)の Web Data Service(WDS)。表 18-10-0004-01「Consumer Price Index, monthly, not seasonally adjusted」 |
| 系列 | vectorId **41690973**(Canada; All-items、coordinate 2.2.0.0.0.0.0.0.0.0、2002=100) |
| 取得 | `POST https://www150.statcan.gc.ca/t1/wds/rest/getDataFromVectorsAndLatestNPeriods`(本文 `[{"vectorId":41690973,"latestN":13}]`)。鍵・登録なし |
| 返るもの | 月ごとの `refPer`(対象月)・`value`(指数)・`releaseTime`(例 2026-09 分は `2026-10-19T08:30`)・`statusCode`・`symbolCode` |
| 値の突き合わせ | 2026-09 の指数 170.0、2025-09 の指数 164.9 → 前年同月比 **3.1%**。The Daily(2026-10-19)の「CPI rose 3.1% year over year in September, following a 3.0% increase in August」と一致 |
| 過去値 | 過去の月の指数が全期間取れる(13期間の取得を確認) |
| 利用条件 | Statistics Canada Open Licence: 世界的・無償・非独占で、利用・複製・公表・配布・**販売**が可。条件は、正確に複製する、StatCan が推奨していると示唆しない、出典を偽らない、法令を守る。出典の表示は、既存の attribution(migration 20261110000002)に StatCan の文言がある |
| 公表時刻 | 8:30 ET。公表予定は `schedule-key_indicators-eng.json`(すでに予定の取り込みで使っている) |

### 未確認・要判断
1. **前年同月比は公式の数字としては返らない**。この表は指数(2002=100)で、前年同月比は「指数 ÷ 12か月前の指数 − 1」を小数第1位に丸めて作る。2026-09 の1点では公表と一致したが、丸めの違いで公表と0.1ずれる月があり得るかは、複数月で未確認。
   - 案A: 計算した値を保存する(公表と全期間一致するか、過去12〜24か月分を The Daily と突き合わせてから)。
   - 案B: StatCan が前年同月比を直接出す表がないか調べる(**未調査**。表 18-10-0006-01 は月次の変化率)。確認できるまで案Aは使わない。
2. **改定の扱い**: CPI は原則として改定されない(季節調整済みの系列を除く)と理解しているが、**未確認**。初回値と改定値を分けて保存する必要があるかは、StatCan の改定方針を確認してから決める。
3. **コア CPI**: カナダには CPI-trim・CPI-median 等があり、「コアCPI」の定義が一つに決まらない。CA_CPI はヘッドライン(全体)として扱い、コアは対象外にする案。HQの判断が必要。
4. `refPer` は月の初日(`2026-09-01`)で返る。既存のパイプラインの対象期間は `YYYY-MM` なので、変換が要る。
5. 既存の `OFFICIAL_VALUE_SOURCES` は、前年同月比の値を直接受け取る形。CA_CPI には「指数から計算する」処理が要り、新しいアダプターになる(実装は承認の後)。

## 2. AU の対象期間(referencePeriod)

### 経緯
2026-11-10 の登録では、ABS の各指標の「latest-release」ページに載る3回分だけに対象月を入れ、それより先(2027-02以降)は「公式に書かれていない」として入れなかった。

### 確認済み(2026-11-13)
ABS の公表カレンダー(月別ページ `https://www.abs.gov.au/release-calendar/future-releases/<YYYYMM>/all`)には、各回に **「Reference period <月> <年>」** が書かれている。**推測ではなく、公式ページの記載。**

読み取りの規則: 各回は「<曜日> <日付> 11:30am <題名> <説明> Reference period <対象月> View current release」の順で、対象月は**その回の題名のすぐ後ろ**にある(次の回の前のものではない)。この規則で読み取った結果が、すでに登録済みの6回(2026-11〜2027-01)の対象月と**全件一致**することを確かめた(規則の検証)。
