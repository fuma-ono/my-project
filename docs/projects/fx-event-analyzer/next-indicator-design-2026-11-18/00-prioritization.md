## 4. 選定
1. **最優先: ユーロ圏 GDP 前期比(`EU_GDP_QOQ`)**。
   - 既存指標との**重複ではない**(ユーロ圏は HICP と失業率だけ。GDP は未対応)。英国・豪州・カナダ・日本の既存指標とも別。
   - 公式の % が**そのまま取れる**(計算不要)ことを、実 API で確認した。
   - 既存の Eurostat の仕組み(取得・日程表・初回値の窓・出典)に乗る。**四半期の期間の扱いだけが新しい**。
2. **次点: 日本のコア CPI**。確認の手順(§5)を踏めば、次の実装の候補になる。
3. 以下は見送り(理由): 小売売上高・鉱工業生産(改定が大きく、影響度が中位。ユーロ圏 GDP の後の拡張に最適。同じ Eurostat の仕組みで足せる)、米国の BEA・Census・DOL(規約・形式の未確認)、カナダ・スイス(影響度・確認不足)。
