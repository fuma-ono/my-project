# FX Event Analyzer: 指標の一覧画面の表示名ルール

**出典**: HQ指示(2026-10-13)。SCR-005 指標一覧など、指標を一覧で並べる画面に出す名前のルールと、主要指標の表示名。

**持ち方**: 表示名は指標ごとに `economic_indicators.display_name` に持つ(api-design v1.21)。アプリは `display_name` を出し、未登録の指標だけ、正式名から「カッコの中の正式名(カッコの前の略称)」の規則で作る。

## 表記で統一するルール

| ルール | 例 |
|---|---|
| 日本語名が短く明確なものは、そのまま | 小売売上高、失業率 |
| 略称が広く定着しているものは、正式名に略称を併記 | 消費者物価指数（CPI）、生産者物価指数（PPI） |
| 一般的な略称を優先するもの | GDP、ISM製造業景況指数、日銀短観 |
| 発表区分が重要なものは、区分を付ける | GDP（改定値）、CPI（前年比）、CPI（前月比） |
| 政策金利は機関名を残す | FOMC政策金利、ECB政策金利 |

- カッコは全角「（）」を使う。
- 国名は名前に入れない(一覧では名前の下に国名を出すため)。
- 1行に入らないときは、カッコの部分を2行目に小さい文字で送る。行の高さは変えない。
