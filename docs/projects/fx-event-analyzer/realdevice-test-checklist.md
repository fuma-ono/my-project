# 実機テストチェックリスト(HQ指示 2026-10-17「実機テスト準備を最優先する」)

作成: 2026-10-17
対象: 知り合いのiPhone実機での動作確認(配布方法が確定した後に実施)
関連: `docs/projects/fx-event-analyzer/realdevice-distribution-plan.md`(配布方法の調査・提案)

このチェックリストは配布方法が未確定の段階で先行して作成したもの。各項目の実施は、
配布(TestFlight/Ad Hoc等、費用承認後)が実際に可能になった時点で行う。

## 0. 前提として明記する既知の制約

テスターに事前共有すべき既知の制約(テスト結果を誤読させないため):

* **為替価格の独立照合は未実装**。品質レポート上は「取得できた/できなかった」(取得率)
  のみを技術的品質として検証しており、別の独立データ源との比較による正確性検証はまだ
  行っていない。
* 経済指標(BLS扱いのCPI・NFP)は「自己一致」(取得元と照合元が同じ)であり、独立照合済み
  件数には数えない。品質レポート上の「独立照合済み: 0件」はこの状態を正しく表している。
* 無料API(Twelve Data等)の商用利用・保存・第三者表示の許諾範囲は未確認(問い合わせ済みだが
  未送信)。実機テスト中に表示される為替データの利用条件は暫定的なものと理解してテストする。

## 1. インストール・起動・ログイン

- [ ] 配布された方法(TestFlight招待 / Ad Hoc .ipa / Xcode直接等)でインストールできる
- [ ] 初回起動でスプラッシュ(SCR-000)→ログイン(SCR-001)へ遷移する
- [ ] 新しいテスト用アカウントでログインできる(新規登録 SCR-002、または既存の付与済みアカウント)
- [ ] ログイン成功後、ホーム(SCR-004)へ遷移する
- [ ] アプリを完全終了→再起動後、ログイン状態が保持されている(または再ログインできる)

## 2. 主要画面の表示確認

- [ ] **ホーム(SCR-004)**: 通貨ペアセクション・お気に入り・直近の要人発言セクションが表示される
      (要人発言は現状常に空状態である点は既知の仕様)
- [ ] **経済カレンダー(SCR-010)**: 画面に遷移できる(現状は仮画面である可能性がある旨をテスターに共有)
- [ ] **指標詳細(SCR-006)**: 指標一覧(SCR-005)から指標を選び、詳細画面が開く
- [ ] **イベント詳細(SCR-007)**: 指標詳細から発表日を選び、特定回の発表結果が表示される
      (Forecast/Actual/Previous、Surprise、乖離理由、関連FXペア)
- [ ] **要人発言詳細(SCR-013)**: 導線があれば開けるか確認(未実装の可能性がある旨を共有)
- [ ] **相場反応詳細(SCR-008)**: イベント詳細から通貨ペアを選び、値動き詳細が表示される

## 3. 相場反応(1分・5分・15分)の表示確認

- [ ] 相場反応詳細(SCR-008)で、1分足の値動きが表示される
- [ ] 同画面で、5分足の値動きが表示される
- [ ] 同画面で、15分足の値動きが表示される
- [ ] それぞれの時間足について、表示されている時刻が発表時刻を基準として正しい範囲か
      (表示時刻のズレ・タイムゾーン異常がないか)
- [ ] 値動きが「未検証」「検証済み」等の状態を伴って表示される場合、その表示が実際の
      データ状態と矛盾していないか(未検証のものを検証済みと表示していないか)

## 4. 異常系の表示確認

- [ ] 機内モード等で通信を切った状態でアプリを開き、適切なエラー・再試行表示になるか
      (クラッシュしない)
- [ ] 通信を戻した後、正常に復帰するか
- [ ] データが存在しない期間・指標を開いた際、空状態の表示が出るか(クラッシュ・無限ローディングにならない)
- [ ] 直近のデータ更新が遅延している場合、「更新が遅れている」ことが分かる表示になっているか
      (更新時刻が古いまま「最新」であるかのように見えないか)

## 5. 品質レポートの検証内訳の確認

- [ ] `/api/v1/quality-report`(トークン付きURL、大野さん/HQから配布)をスマートフォンの
      ブラウザで開ける
- [ ] レポート内の「独立照合済み/自己一致/単一ソース・未照合/差異あり/未発表・確認待ち」の
      区分が表示されている
- [ ] 「差異あり」件数がある場合、対象指標・対象期間・比較元が表示されている
- [ ] このURLは知り合いテスター全員には配布しない(大野さん/HQの確認用。§0の制約と合わせて、
      テスターへの一般公開は想定していない)

## 6. 複数端末・複数ユーザーでのデータ分離

- [ ] 2つ以上の端末で異なるテストアカウントにログインし、一方の設定(お気に入り通貨ペア等)
      が他方に影響しないことを確認する
- [ ] 同一端末で一度ログアウトし、別アカウントでログインした際、前のアカウントのデータが
      残っていないことを確認する

## 7. 不具合の記録方法

知り合いテスターが実機で気づいた不具合は、以下の情報を添えて大野さん経由でHQへ共有する:

1. 発生した画面(SCR番号、または画面名)
2. 発生した操作の手順(再現手順)
3. 発生した日時・端末のOSバージョン・端末モデル
4. スクリーンショット(可能な場合)
5. 期待した動作と、実際に起きた動作の違い

この記録はテスターへの配布時に案内文として同封する(配布方法確定後、別途作成)。
