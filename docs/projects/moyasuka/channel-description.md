# チャンネル概要欄(モヤスカ)

オーナーがチャンネル作成時に「概要」欄へそのままコピペできる文面。バナーの書き出し(`docs/projects/moyasuka/naming.md`で決めた「モヤスカ|LINEで見るスカッと系ショートドラマ」)と統一感を持たせた構成にしている。

**2026-08-06 改訂**: オーナーから紹介された参考動画([嫁のクイズに答え続けた旦那の逆襲ｗｗ](https://youtube.com/shorts/khhWR7N1LaM))のチャンネル「[笑うバナナLINE](https://youtube.com/channel/UCzpzhbRBG_bXjmtetyRw9qQ)」(登録者15.3万人・総再生6.2億回・動画757本、この分野で実際に伸びている実例)の概要欄構成をAPIで取得し、構成を揃えた。

## コピペ用本文

```
LINEのやりとりで展開する「スカッと系」ショートドラマチャンネルです。
モヤモヤする出来事も、最後はちゃんとスカッと気持ちよく終わる。そんな物語を毎日お届けします。

■ 投稿ペース
毎日20:00更新

■ こんな方におすすめ
・スキマ時間でサクッと見られるドラマが好き
・モヤモヤ→スカッとする展開が好き
・LINE風のショートドラマをよく見る

【使用音声】
Google Cloud Text-to-Speechによる音声合成を使用しています

【ネタ募集】
実際にあった「モヤモヤ→スカッと」なLINEエピソード、募集中です。X(@moyasuka_ch)にDMいただけると嬉しいです✨

■ ご注意
本チャンネルのストーリーはすべてフィクションです。実在の人物・団体とは一切関係ありません。

チャンネル登録して、今日のモヤモヤをスカッと解消しませんか?

#スカッと #LINEドラマ #ショートドラマ
```

## 構成の意図

- **冒頭2文**: 何のチャンネルかを即座に伝える(スカッと系ジャンルのキーワードを自然に含める、`docs/projects/moyasuka/naming.md`の競合調査を踏襲)
- **投稿ペース**: `docs/projects/moyasuka/posting-policy.md`で決定した毎日20:00 JSTをそのまま明記。視聴者の習慣化を狙う
- **【使用音声】**: 「笑うバナナLINE」の実際の概要欄と同じ見出し・文言(「※動画のキャラに合わせて使用させていただいております🙇‍♂️」)に揃えた。VOICEVOXの利用規約でクレジット表記が求められる想定にも対応(`docs/projects/moyasuka/team.md`の法務/コンプライアンス担当チェック項目)。キャラクターは固定配役(`docs/projects/moyasuka/content-backlog.md`のキャスト運用)通り、ずんだもん・四国めたん・玄野武宏の3名を明記
- **【ネタ募集】**: 同じく「笑うバナナLINE」の概要欄にある「ネタ募集」枠を参考に新設。ネタ帳(`docs/projects/moyasuka/content-backlog.md`)の消化ペースが投稿頻度(毎日)に追いつかなくなった時の供給源として機能する。**2026-08-10方針転換**: 当初は既存の`@QuietHoursceo`(全社の透明性発信アカウント)を窓口に流用する予定だったが、ブランドが異なる(モヤスカは匿名投稿ドラマ、`@QuietHoursceo`はAI社長の経営実況)ため、**モヤスカ専用の新規Xアカウントを新設してそちらに一本化**することにオーナーが方針転換(理由: X投稿の自動化はオーナー自身のPCが前提の仕組みで、オーナーがiPhone/iPadのみ・PC無しと判明しているため今のところ実現できず、**X関連は当面すべて手動運用**と決定)。**2026-08-18: オーナーがアカウント作成完了、ハンドルは`@moyasuka`ではなく`@moyasuka_ch`で確定**(https://x.com/moyasuka_ch — 第一候補`@moyasuka`は取得できなかった様子。上記ネタ募集本文もこの確定ハンドルに合わせて更新済み)
- **ご注意(フィクション表記)**: 台本が実在の人物・団体を示唆しないための保険として明記。BGM/note/アプリ各事業のプライバシーポリシー・利用規約と同じ「正直に開示する」方針を踏襲
- **ハッシュタグ**: 実際に伸びている競合チャンネル(スカッとLINE、LINE劇場等)のタイトル傾向調査で確認した検索キーワードを反映(`docs/projects/moyasuka/naming.md`)。参考動画は`#マイクラ`タグも付けているが、うちの背景映像は実写マイクラ映像ではない(`docs/projects/moyasuka/background.md`)ため付けていない — 実態と違うタグを付けない方針
