# 背景映像のデザイン決定(モヤスカ)

参考にした形式(「笑うバナナLINE」等)はマイクラのパルクール等、実写のゲーム実況映像を視聴維持率のために使っている。うちはこの部分を自前生成に置き換えた。理由: 実写ゲーム映像を継続的に調達・録画するのは(a)この環境では実行不可能、(b)オーナーの手元PCでの録画作業が継続的に発生する、(c)著作権的にグレーな運用になりがち。`bgm_pipeline`の音源・サムネイルと同じ「100%自前生成、権利関係がクリーン」という方針をここでも踏襲する。

## 反復の記録

1. **v1: ぼかしたブロブの混色(ラバランプ風)** — オーナー: 「もう少し特徴のある感じがいいな」
2. **v2: チャット吹き出しが漂う版** — コンテンツ内容(LINE風の会話ドラマ)と直結するモチーフに変更。オーナー: 「すこしゲーム性のあるというか、そっちにも目が行ってしまう感じがあるといいかも」(マイクラのパルクール映像が持っている「思わず見てしまう」性質を求めている)
3. **v3: 円形アリーナ内で物理演算バウンドする版** — 重力なし・等速反射(古典的な「ボールが円の中で跳ね回る」満足系動画の定番手法)。チャット吹き出しの尻尾を残してテーマ性も維持
4. **v4(採用): ボールの数が増減する版** — オーナー: 「これにボールが増えたり減ったりするのはどう?」。3〜9個の間で、出現(拡大アニメーション)・消滅(縮小+フラッシュ)がランダムなタイミングで発生。長尺ループでも単調にならない

## 実装

`moyasuka/background_gen.py`。外部素材・実写映像は一切使用しない(PIL/numpyによる完全自前生成)。

```bash
python3 moyasuka/background_gen.py --seconds 60 --seed 1 --out background.mp4
```

`--seed`を変えると毎回違う配置・タイミングになる(動画ごとに単調な使い回しを避けるため、`bgm_pipeline`のプリセットローテーションと同じ考え方)。
