# モヤスカ 若者向けリニューアル・ネタ募集型自動化(方針記録、2026-08-18)

オーナー指示(2026-08-18、2件)を受けた方針記録。**まだ実装していない**——下記の未解決論点が固まってから着手する。「今後でいいから進め方を変えて」という指示なので、緊急実装ではなく方向転換の記録として残す。

## 指示された変更点

1. **テーマの若者向け固定**: 恋愛/いじめ/友達関係/家族(毒親・過干渉)/学校生活/SNSトラブルを中心に台本を自動生成
2. **ネタ募集導線**: メール(story@xxxx.com想定)+ XのDM開放。「あなたの体験を送ってください」を固定表示
3. **投稿処理パイプライン**: 要約→登場人物・状況抽出→感情軸特定→モヤスカ形式台本化→ナレーション/UI/既読/通知音の自動生成→背景合成→ショート化
4. **若者向け台本テンプレ**: 冒頭「ねぇ聞いて…」等の若者口調+通知音、中盤で感情爆発、終盤オチ/余韻、短め
5. **背景**: 波をやめ、マイクラアスレ動画を分割・ローテーション管理して使用(別途2026-08-18の指示で詳細あり)
6. **完全自動化**: ネタ受信→自動台本化→自動レンダリング→自動公開、毎日公開、台本在庫5〜10本を常時維持

## 未解決の論点(実装前に方針を決める)

### A. 背景動画の取得・権利関係(既存の別指示と共通)
- このサンドボックスからYouTubeの動画/CDNへの通信がブロックされており、指定URLの動画をダウンロードできない(技術制約、過去複数回確認済み)
- 「フリー素材のため利用可能」の実際の根拠(自作か、CCライセンスか、他者の動画か)が未確認。他人のYouTube動画をそのまま収益化チャンネルの背景に使うのは著作権リスクが残る
- → オーナー側でダウンロード・権利確認の上、ファイルを直接渡してもらう必要がある(chat添付 or Dropbox経由)

### B. ネタ募集の自動処理と人間レビューの線引き
恋愛・友人関係の「スカッと系」創作(既存01〜05)と違い、いじめ・毒親・SNS晒しといったテーマは**実際の10代投稿者の本物の体験**が届く可能性がある。完全無人で「受信→要約→台本化→レンダリング→公開」まで流すことには以下のリスクがある:

- 投稿者が未成年である可能性(本人特定・学校名等の混入リスク)
- 実際の加害者を特定できる書き方になるリスク(名誉毀損)
- 自傷・希死念慮等のセンシティブな内容が来た場合に、エンタメとして自動処理してしまう危険性

**提案**: 「実話ベースの投稿を採用するかどうか」の可否判断だけはオーナー確認を挟む(既存の`/MoyasukaSubmissions`Dropbox運用と同じ形)。台本化・レンダリング自体は自動化してよいが、採用の一線だけは人が見る。

### C. 完全自動公開への移行タイミング
モヤスカはこれまで一度もYouTubeへ実際に自動公開されたことがない(すべてオーナー確認済みの手動判断)。「レンダリング→公開まで無人」への切り替えは大きな変更なので、最初の数本はこれまで通りレビューを挟み、問題なければ段階的に自動化する進め方を提案する。

### D. 既存資産との整合
- `content-backlog.md`の現行バックログ(#06〜10)は義母・ママ友・上司など大人の対人関係が前提。若者向けに転換する場合、バックログ自体の再設計が必要
- `channel-description.md`の「ご注意」(全話フィクション表記)は実話ベース投稿を扱う場合、表記の見直しが必要になる可能性がある
- キャスト運用(義母=四国めたん、旦那=玄野武宏等)は若者向けキャラクター(同級生・恋人・親等)に合わせて再設計が必要

## 次のアクション

B・Cの方針(人間レビューの入れ方、自動公開への移行段階)が固まり次第、以下を実装する:

4. 背景ローテーション機構(Aの解決後)
