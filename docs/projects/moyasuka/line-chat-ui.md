# LINEチャットUI化(モヤスカ)

オーナー指示(2026-08-06)「ラインのようなやり取りにして」を受けて、動画の見せ方を作り直した。同日中に2回、実際の映像を見たオーナーからの追加フィードバックで調整を重ねている。

## v1: 字幕方式 → LINEチャット方式へ

それまでの`assemble_video.py`は、台本の地の文をそのまま白文字の字幕として画面下に焼き込んでいた。チャンネルのコンセプトは「LINE風の会話ドラマ」なのに、実際の映像は普通のナレーション動画になっていた——見せ方のズレだった。

`moyasuka/line_chat.py`を新設し、台本そのものをLINEのメッセージのやり取り(誰が・何を送ったか)として書き、実際のチャット画面のように吹き出しが1通ずつ流れてくる映像に作り直した。

## v2: メッセージをコンパクトに、連投をグループ化

オーナー:「文章をもう少しコンパクトに、チャット風だから」

- 1メッセージ1〜2文だった台本を、実際のLINEのように短文を連続送信する形に書き直し
- 実装してみると、短文化で同一話者の連続メッセージが増え、そのたびに名前・アイコンが繰り返し出るのが不自然だったため、連投では最初の1通だけに表示する仕様に変更(実際のLINEの「連投」表示と同じ)

## v3: 内容を面白く・1分尺に、ナレーションカード廃止、パネルを縮小して上に

オーナー:「話が面白くないし、短い。ショート動画用に1分動画にして。あと後ろのボールが見えないからもう少しチャット画面は小さく、そして、上にして、心の声とかいらない」

4点まとめて対応:

1. **尺を1分に**: 台本を29ターンに増量(以前は17ターン、約41秒)。ただ長くするのではなく、後述の内容強化と合わせて実質的な情報量を増やした結果として尺を伸ばした
2. **内容を面白く**: 具体的な数字(掃除613回・洗濯890回・料理1200回)を出す「証拠」の見せ方を強化し、第三者(叔母)が会話に途中参加して驚く反応を追加。第三者の反応が入ることで「まわりも味方する」スカッと感が増す、という定番の型を踏襲
3. **ナレーションカード廃止**: 状況説明の`> テキスト`カードを全廃。物語は完全にキャラクターが実際に打った発言だけで進むように書き直した。「心の声」的な地の文はゼロ。`parse_chat_script`のパース機能自体は残してある(将来また使う可能性のための後方互換)が、台本では使用しない
4. **チャットパネルを縮小し、上部に配置**: パネルを画面下端まで伸びる「ボトムシート」から、画面上部に浮かぶ固定高さの「カード」に変更(角丸を四隅すべてに)。空いた下部の広いスペースをボール背景に譲った

### レイアウト変更の詳細

| 項目 | v1〜v2 | v3 |
|---|---|---|
| パネル位置 | `PANEL_TOP=360`〜画面下端(920px) | `PANEL_TOP=50`〜`PANEL_BOTTOM=700`(650px) |
| 角丸 | 上2つのみ(ボトムシート) | 四隅すべて(浮かぶカード) |
| ボール背景の可視範囲 | 上部360pxのみ(ほぼアーチの先端しか見えない) | 下部580px(700〜1280)、アリーナ全体が収まる |

`background_gen.py`のアリーナ位置(`ARENA_CY`)も`H*0.42`→`H*0.77`に、半径も300→230に変更し、パネル下の広い空間にちょうど収まるよう再調整した(ボールのスピード・サイズも比率を保つよう調整)。この位置決めはLINEチャットUIのレイアウトに合わせたもので、背景映像パイプライン自体の設計判断(v1〜v4の反復)を覆すものではない。

## 画面構成(720x1280、確定版)

- **上部(50〜700px)**: 白い浮かぶチャットカード。上端にLINE風の緑ヘッダーバー(グループ名表示)、その下にメッセージがスクロール表示される
  - 自分(「私」)の発言 → 緑の吹き出し、右寄せ
  - 相手の発言 → 白い吹き出し、左寄せ。同一話者の連投は最初の1通だけ名前・アイコン表示、間隔を詰める
- **下部(700〜1280px)**: ボール背景がフル表示。円形アリーナ内で物理演算バウンドする吹き出し型のボールが、数を増減させながら動き続ける

## 台本フォーマット(scripts/*.md)

`---`より下を以下のルールでパース:

- `グループ名: ◯◯` → ヘッダーバーに表示するグループ名
- `話者: メッセージ` → チャットの発言。話者が「私」なら自分の発言(緑・右)、それ以外は相手の発言(白・左、初出のみ名前表示)
- (`> テキスト`のナレーションカード構文はパーサーに残っているが、v3以降の台本では未使用)

3本の台本(`scripts/01〜03`)はこの形式で書く。01は上記の内容強化・1分尺化を反映済み、02・03は今後同様に更新する。

## 実装・確認したこと

- `background_gen.py`から`compose_frame`/`iter_frames`を切り出し、`line_chat.py`が同じボール物理演算のフレームをそのまま再利用できるようにした
- 全メッセージを毎フレーム再描画していたレンダリング遅延を、吹き出し画像のキャッシュ化で解消(初回テストは2分でタイムアウト → 修正後1381フレームを2分7秒で完了)
- 各バージョンを実際にレンダリングし、複数時点のフレームを目視確認してから次の修正に進んでいる(推測での修正はしていない)

## 使い方

```bash
python3 -m moyasuka.line_chat \
  --script moyasuka/scripts/01-sample.md \
  --seed 4 \
  --audio /tmp/narration.wav \
  --out moyasuka-01.mp4
```

`--audio`省略時は無音のプレースホルダーで尺を概算(VOICEVOX未セットアップでもパイプラインの動作確認ができる)。
