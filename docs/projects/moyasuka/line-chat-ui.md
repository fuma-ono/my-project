# LINEチャットUI化(モヤスカ)

オーナー指示(2026-08-06)「ラインのようなやり取りにして」を受けて、動画の見せ方を作り直した。

## 何が変わったか

それまでの`assemble_video.py`は、台本の地の文をそのまま白文字の字幕として画面下に焼き込んでいた。チャンネルのコンセプトは「LINE風の会話ドラマ」なのに、実際の映像は普通のナレーション動画になっていた——これは見せ方のズレで、指摘の通り。

`moyasuka/line_chat.py`を新設し、台本そのものをLINEのメッセージのやり取り(誰が・何を送ったか)として書き、実際のチャット画面のように吹き出しが1通ずつ流れてくる映像に作り直した。

## 画面構成(720x1280)

- **上部(〜360px)**: 既存の背景映像(円形アリーナでボールが物理演算バウンド)がそのまま見える。2026-08-05に決めた「ボーっと見れる背景」の役割はここに残している
- **その下**: 白いボトムシート状のチャットパネル。上端にLINE風の緑のヘッダーバー(グループ名を表示)
- **チャットパネル内**: 
  - 自分(「私」)の発言 → 緑の吹き出し、右寄せ(実際のLINEの送信メッセージと同じ配色)
  - 相手の発言 → 白い吹き出し、左寄せ、名前ラベルと丸アイコン付き
  - ナレーション(状況説明)→ 中央寄せのグレーのピル型カード(LINEの「システム通知」「日付区切り」と同じ見た目)
  - 新しいメッセージが増えるとパネル内でスクロールし、古いメッセージは上端でクリップされる(実際のチャットアプリと同じ)

## 台本フォーマット(scripts/*.md)

`---`より下を以下のルールでパース:

- `グループ名: ◯◯` → ヘッダーバーに表示するグループ名
- `> テキスト` → ナレーションカード(状況説明)
- `話者: メッセージ` → チャットの発言。話者が「私」なら自分の発言(緑・右)、それ以外は相手の発言(白・左、名前表示)

3本の台本(`scripts/01〜03`)は全てこの形式に書き直し済み。地の文の物語をチャットのやり取りに翻案する形になっているので、以降の新規台本もこの形式で書く。

## 実装・確認したこと

- `background_gen.py`から`compose_frame`/`iter_frames`を切り出し、`line_chat.py`が同じボール物理演算のフレームをそのまま再利用できるようにした(挙動は変更なし、既存の背景映像パイプラインには影響なし)
- 実装直後に2つの問題を発見・修正(実際にフレームを目視して発覚):
  1. 全メッセージを毎フレーム再描画していたため、レンダリングが極端に遅かった(1回目のテストは2分でタイムアウト) → 吹き出し画像を台本ごとに1回だけ描画してキャッシュし、フレームごとには「どれを表示するか」だけ選ぶ方式に変更
  2. (特になし、文字の折り返し・文字化けは`assemble_video.py`で先に踏んだ轍を最初から踏まえて実装したため今回は初回から問題なし)
- 台本01で実際にレンダリングし(2分7秒、1381フレーム)、複数時点のフレームを書き出してオーナーに送付・確認依頼中

## 使い方

```bash
python3 -m moyasuka.line_chat \
  --script moyasuka/scripts/01-sample.md \
  --seed 4 \
  --audio /tmp/narration.wav \
  --out moyasuka-01.mp4
```

`--audio`省略時は無音のプレースホルダーで尺を概算(VOICEVOX未セットアップでもパイプラインの動作確認ができる、`assemble_video.py`と同じ設計)。

## 今後

- `assemble_video.py`(地の文をそのまま字幕にする旧方式)は現在は使わない。台本も新形式に書き換え済みのため、そのまま実行しても正しくパースできない
- VOICEVOXセットアップ後は、無音プレースホルダーを実際のナレーション音声に差し替えるだけで本番投稿が可能
