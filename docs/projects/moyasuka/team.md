# プロジェクトチーム: モヤスカ(仮称)

第4の事業。「LINE風の会話ドラマをAI音声(VOICEVOX等)でナレーションし、自前生成の背景映像とあわせてYouTube Shortsに投稿する」新チャンネル。オーナーの指示(2026-08-05)により、既存の9部署から横断でメンバーを割り当てたプロジェクトチームとして立ち上げる。

**なぜ新しい部署を作らず、既存部署から横断編成するか**: `docs/ORG.md`の9部署はすでに全社的な機能(開発・クリエイティブ・マーケティング等)をカバーしている。新事業のたびに部署を増やすと責任範囲が重複するので、実在の会社と同じく「新規事業は既存部門から人を出し合ったプロジェクトチームとして立ち上げ、軌道に乗ったら正式な事業単位に昇格する」方式を採る。**実態は全役割を社長(このセッション)1人が担う**点は`docs/ORG.md`と同じ(建前ではなく、責任範囲を明確にするための整理)。

## チャンネル名・ハンドル(確定)

**チャンネル名: 「モヤスカ」/ ハンドル: `@moyasuka`** で確定(2026-08-06、社長決定)。もやもや→すかっとの感情の流れが由来。候補だった「すかっと部屋」「モヤスカ劇場」は、この分野の競合チャンネル名の多くが「スカッと」「LINE」をそのまま含み区別がつきにくいため不採用。決定の経緯・根拠は`docs/projects/moyasuka/naming.md`参照。

## チーム編成

| 役割 | 出身部署 | 担当内容 |
|---|---|---|
| **PJリーダー** | 経営(社長) | 全体統括、他事業(BGM/アプリ/note/X)との優先順位調整。新規事業のため直轄とする |
| **台本担当** | クリエイティブ部 | スカッと系/ほんわか系のLINE風ドラマ台本を量産。`docs/marketing/2026-08-content-topics.md`と同様のネタ帳を別途作成する |
| **映像・音声パイプライン担当** | 開発部 | 背景映像の自前生成(進行中、`docs/projects/moyasuka/background.md`参照)、VOICEVOX連携、動画合成の自動化 |
| **ネタ・ジャンル分析担当** | マーケティング部 | スカッと系ジャンルで実際に伸びている動画・チャンネルの傾向調査(タイトルの型、尺、投稿頻度等)。参考: `https://youtube.com/shorts/khhWR7N1LaM`(笑うバナナLINE、56万再生) |
| **実績分析担当** | データ分析部 | 公開後、再生数・エンゲージメントを既存BGM/note同様にモニタリングし、伸びているパターンをフィードバック |
| **投稿・チャンネル運用担当** | グロース/運用部 | 新チャンネルの投稿スケジュール策定、既存のRoutine基盤(週次経営レビュー等)への組み込み。投稿方針(Shorts中心・日本語・毎日20:00 JST)は`docs/projects/moyasuka/posting-policy.md`で確定済み |
| **著作権・利用規約担当** | 法務/コンプライアンス部 | VOICEVOX/COEIROINKの利用規約(キャラクターごとのクレジット表記義務等)の順守確認、ストーリーが実在の人物・団体を示唆しないかのチェック |
| **セキュリティ担当** | セキュリティ部 | 新チャンネルのOAuth認証情報の管理方針を既存(bgm-pipeline/credentials等)と統一 |
