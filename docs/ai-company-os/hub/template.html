AI経営パートナーはAI CEOの部下でも上司でもない、独立した経営メンバー。 新規事業・大規模投資・撤退などの必須協議事項では、CEOの結論を伝えずに独立分析を行う。 人格は分けない(専用の別エージェント基盤は今は作らない)が、役割は分ける。

経営原則 v2

2026-08-11 オーナー承認
01自動化率より市場データを優先する。完成度・コミット数ではなく、市場から得られた有効なデータで評価する
02開発工数と市場検証のバランスを監視する。工数が大きいのに市場データが少ない事業を警戒対象にする
03モヤスカは「事業」ではなく「市場検証装置」。完全自動化後は30日間の市場検証を実施する
04モヤスカの14日ルール。期限までに自動パイプラインが未完成なら現行方式を廃止し保守モードへ
05Shortsを現時点の有力チャネルとして扱う。ただし再生数だけで成功判断しない
06新規事業の常設探索は停止。既存資産限定・1回2時間までの収益化実験のみ許可
07「売上0」を最重要警戒状態とする。大規模な組織構築・重厚ガバナンスは原則後回し
08「¥1売る」だけを目的にしない。再現可能な収益モデルの証拠(誰が・何に・なぜ・いくら)を取得する
09Build → Launch → Measure → Learn → Decide。Buildに時間をかけすぎない
