# コンテンツネタ帳(マーケティング部)

「読者が食いつくネタ」を実際に調査した結果と、3事業(note/BGM動画/アプリ)を横断するトピックバックログ。

## 調査結果の要点

**A) noteで「スキ」がつく記事の型**
- 効くタイトルの条件: ①要約になっている ②数字が入る ③誰向けか明確
- ノウハウの羅列より「〇〇してみた→こう気づいた」という**失敗談・気づき型**が刺さる
- フォロワー0の初心者ほど、「私の話」ではなく「あなたに関係あるかも」という当事者性が鍵
- → 1本目の「AIで雨音を作ってみた」はこの型に完全一致。次は失敗談・比較・悩み解決を軸にする

**B) 読者の実際の検索・悩み**
- 睡眠は「寝れない時どうすれば」等の即効性の高い実用検索が定番(Yahoo知恵袋)
- 雨音が眠くなる理由は「1/fゆらぎ」「θ波」など**科学的な"なぜ"への知的好奇心**が強い
- ADHD・発達障害グレーゾーン層の「音がうるさくて集中できない」「ホワイトノイズで改善した」という当事者体験談への需要が強く、在宅ワーク×子育て世代の悩みとも重なる
- lo-fi/アンビエントは「勉強用BGM」から「タスク特化のAI生成サウンド」へ文化的に進化中。ASMR/音フェチはTikTokで根強い

**C) 3トラックを自然につなぐ物語**
- 最も相性がいいのは「作った理由(Why I built X)」型のストーリー。宣伝色を出さずに開発の背景・失敗・気づきを語ると、note→動画→アプリへ自然に流入する
