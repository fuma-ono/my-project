# BGM動画チャンネルの投稿計画(2026-08-03)

オーナーから「投稿計画があるのか、同じ動画を出し続けていないか、Shortsで登録者を増やす導線があるのか」という指摘を受けて策定。それまでは計画と呼べるものがなく、実際に2本連続で同じプリセット(`sleep_rain_focus`)を投稿してしまっていた。

## それまでの状態(反省点)

- 自動スケジュールなし。社長(このセッション)が気づいた時に手動で投稿していただけ
- プリセットのローテーション管理がなく、同じ内容を繰り返し投稿するリスクがあった(実際に発生した)
- YouTube Shortsへの自動投稿の仕組みが存在しなかった(縦動画はローカル生成のみで、アップロード経路がなかった)
- プリセットが4種類のみで、週1本ペースだと1ヶ月で一巡する

## 実施した対応

### 1. ローテーション管理(`bgm_pipeline/rotation.py`)

長尺動画・Shorts、それぞれ独立したローテーションで、全プリセットを順番に一巡させる。状態は`bgm-pipeline/rotation_state.json`(gitで追跡、シークレットではない)に記録。`publish.py`・`publish_shorts.py`は`--preset`を省略すると自動的に次のプリセットを選ぶ。

### 2. YouTube Shorts自動投稿(`bgm_pipeline/publish_shorts.py`、新規)

45秒程度の短尺クリップを生成・アップロード。概要欄に対応する長尺動画へのリンクを入れられる(`--link-video-id`)ことで、「Shortsで見つけてもらう→長尺動画に誘導→視聴時間が伸びる→登録者が増える」という導線を作る。

### 3. 投稿ペース(提案)

| 種別 | 頻度 | 備考 |
|---|---|---|
| 長尺動画(YouTube) | 週1本 | 現在4プリセットで一巡、新プリセット追加で希釈させる |
| Shorts(YouTube) | 週2〜3本 | 直近の長尺動画1本につき2〜3本の切り抜き的Shortsを出し、長尺への導線にする |
| Reels(Instagram) | Shortsと同素材を流用 | Meta連携済み(Appレビュー待ち) |
| TikTok | 手動 | 自動投稿の仕組み未実装、アカウント作成もまだ |

「週3〜5本のShorts」という当初方針は、今のプリセット数・運用体制だと質を落とさず出し続けるのは現実的でないと判断し、週2〜3本からスタートして様子を見る。

## 今後やるべきこと(未着手)

- **プリセットの拡充**: 現在4種類。最低でも8種類程度に増やし、長尺動画のローテーションが月1周にならないようにする(クリエイティブ部のタスクとして別途着手)
- **投稿の自動化(要オーナー判断)**: 今は全て手動トリガー。定期実行(Routine)を組めば「週1本・週2〜3本のShorts」を人手を介さず回せるが、実際に公開する行為を無人で自動化することになるため、オーナーの意向を確認してから設定する
- **Shortsのサムネイル**: 現状は自動生成frame任せ。Shortsはスワイプ視聴が主でサムネイルの影響は長尺より小さいと考えられるため優先度は下げているが、検索結果に出た場合の改善余地はある
- **視聴データに基づく改善**: YouTube Analyticsのスコープ取得(別タスク)が済み次第、どのプリセット・どのタイトルが伸びているかを見て、ローテーションの重み付けやタイトル文言を調整する
