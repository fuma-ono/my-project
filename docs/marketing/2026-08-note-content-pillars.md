# noteコンテンツの2本柱化とアフィリエイト方針

## 背景

note事業を「BGM/アプリと同じ世界観の記事のみ」から広げ、読者層を増やす施策として2本柱化を採用する。あわせて、追加コストゼロで実行できるアフィリエイト収益も導入する。`docs/marketing/2026-08-strategy-decision.md` の判断に基づき、虚偽の前提(架空の4事業目)を含まない形で採用する。

## 柱A: 睡眠・集中サウンド(既存路線)

これまで通り。`docs/marketing/2026-08-content-topics.md` のバックログを使用する。

## 柱B: 個人開発・AI経営の裏側(新設)

AIに経営の実行部分を任せて会社を回す、というこの会社自体の成り立ちをコンテンツにする。事業(BGM/アプリ/note)のPRになりすぎず、「実際どうなっているか」を正直に書くことで柱Aとは違う読者層(個人開発・スタートアップ・AI活用に関心がある層)を獲得する狙い。

**初回記事の方針転換について**: 当初「AIに経営を任せてみたら会社が4つになった話」という案があったが、これは実装が伴わない事業(経費管理アプリ)を前提にした内容だったため採用しない。代わりに、実際に起きたこと(アカウント作成の壁、Googleアカウントの誤凍結、セッション間の情報不整合をどう発見して訂正したか等)をベースにした実話記事に差し替える。誇張なしの実話の方が、柱Bの読者層には刺さりやすいという判断もある。

## アフィリエイト方針

- Amazon アソシエイト・楽天アフィリエイトを導入する(登録・審査は無料、オーナー側の操作が必要)
- 記事内で自然に紹介できる文脈がある場合のみリンクを貼る(無理に商品を挿し込まない)。柱Aなら「睡眠グッズ」「ホワイトノイズマシン」等、柱Bなら「個人開発の参考書籍」等
- 貼り付けたらステルスマーケティングにならないよう、記事内に広告であることを明記する(アフィリエイトリンクである旨のひとこと)

## オーナー側で必要な作業

- Amazonアソシエイト・楽天アフィリエイトへの登録(それぞれ無料、審査あり)
- 登録が完了したら、発行されたリンクIDを教えてもらえれば記事への組み込みを行う
