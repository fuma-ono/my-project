# note記事アフィリエイト方針(社長決定, 2026-08-01)

「noteとSNS(記事+導線)以外に売上を上げる方法はないか」への回答として、既存の記事制作フローに追加コストなしで乗せられる収益源を優先した。

## 決定

1. **アフィリエイト(Amazonアソシエイト / 楽天アフィリエイト)を今すぐ開始する。**
   記事を書く手間は変わらず、新規のコンテンツ制作コストがゼロ。フォロワー数の審査条件も定期マガジンより緩いことが多く、フォロワー0の現段階でも収益化を狙える数少ない手段。
2. **Kindle電子書籍化は保留(判断基準つきで様子見)。**
   現状は公開1本+下書き3本の計4本のみで、書籍としてまとめるには薄い。目安として**下書き含め8〜10本(月2〜3本ペースで2〜3か月後)** に到達した時点で再検討する。`note-articles/README.md` の「今後の検討」に記録済み。理由: 中途半端な本数でKindle化しても内容が薄く、労力に見合うリターンが見込みにくいため。

## 実施方針(アフィリエイト)

- 対象商品: 記事テーマ(睡眠・集中・作業用サウンド)と自然につながるもの限定。イヤホン/ヘッドホン、アイマスク、耳栓、ホワイトノイズマシンなど。無関係な商品は貼らない(信頼を損なうため)。
- 配置: 記事本文の最後、「今回の話に関連して」のような一言を添えた自然な形でのみ。本文中に埋め込んで誘導色を強めない。
- 表記義務: 景品表示法のステルスマーケティング規制により、**「本記事にはアフィリエイトリンクを含みます」等のPR表記が必須**。記事末尾に定型文で明記する(→ `docs/legal/checklist.md` に追記済み)。
- リンク形式: 実際のアソシエイトタグはオーナーのアカウント作成後に発行されるため、下書き段階では `{AMAZON_ASSOC_TAG}` のプレースホルダーを使い、投稿直前にオーナー側で置換する運用とする。

## オーナーへの依頼

- Amazonアソシエイト、楽天アフィリエイトへの登録・審査申請(社長側では代行不可)
- 発行されたアソシエイトタグの共有(下書き内プレースホルダーの置換に使用)
