## 2026-11-21 料金仕様 v1 の実装方針
- **保存先は SQLite(標準ライブラリ)**: 利用枠の予約・消費・返却を `BEGIN IMMEDIATE` の1トランザクションで行い、同時リクエストやリトライでの二重消費を防ぐため。外部 DB(有料の可能性)は使わない。
- **価格・上限・商品 ID は `config/plans.json`**: 仕様の「調整可能な構造」に合わせ、コードを変えずに変えられるようにする。
- **新規編集は「最初の書き出しの成功」で消費**: 解析の失敗は返却する。書き出しの失敗は、やり直せる間は予約のまま。ジョブの削除・期限切れ・エラーで返却する。
- **AI 再編集のために、作業フォルダの transcript.json と mix.wav をジョブの期限まで残す**: 再編集で文字起こしを省き、字幕だけの変更では音声のミックスを使い回すため(仕様「可能な限り変更部分だけ再処理」)。AC-E3 の「大きな一時ファイルを消す」の例外。ディスク: 10分の素材で mix.wav は約230MB(32bit float、48kHz ステレオ)。
- **解像度の上限は短辺で判定**(FREE 720 / STANDARD・PRO 1080 / PRO の 4K は `allow_4k` と素材の条件がそろったとき)。字幕は元の解像度で焼き込んでから縮小する。
- **App Store の検証はサーバー内で JWS の証明書チェーンと署名を確かめる**(`cryptography`、無料・オープンソース)。App Store Server API(API キーが必要 = 有料の開発者登録)は使わない。本物のルート証明書・商品 ID の配置は人間の承認後。
- **依存の追加: `cryptography>=42`(optional `billing`)**: App Store の署名付き取引(JWS、ES256)と証明書チェーンの検証に使う。Apache-2.0 / BSD の無料ライブラリ。CI と `make setup` は `.[test,bgm,billing]` を入れる。
