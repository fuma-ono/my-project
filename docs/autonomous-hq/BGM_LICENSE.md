# BGM の調査(2026-11-22)

**結論: 商用アプリへの組み込み・完成動画への埋め込み・ユーザーの保存や SNS 投稿までを、個別の曲で確認できた CC0 音源は、まだ無い。購入・採用はしない(オーナー判断待ち)。**

## 確認したことと、していないこと
| 取得元 | 到達 | 結果 |
|---|---|---|
| Free Music Archive | 200 | 「Public Domain」「商用利用」の絞り込みがあるが、曲ごとのライセンスページの確認が必要。JavaScript 中心のページで、個別の曲の確認は未実施 |
| OpenGameArt(CC0・音楽) | 200 | 一覧は取れた(5 Chiptunes、Battle Theme A、Town Theme RPG など)。**ゲーム用のチップチューン・BGM が中心で、Vlog・旅行には合わない**。CC0 は投稿者の申告で、権利の確認は第三者が行っていない |
| archive.org(CC0 表示) | 200 | 投稿者の自己申告で信頼できない(動画で、権利が明らかに CC0 でないものが上位に並んだ)。音楽は、朗読(LibriVox)が上位 |
| Coverr の音楽 | 200 | 動画と同じライセンス。**AI の評価・学習への利用不可**の条項が音楽にも及ぶ(STOCK_DATASET の訂正を参照) |
| Mixkit の音楽 | 200 | 「Stock Music Free License」の本文を取得できなかった。確認できないので採用しない |
| Freesound | 301 | 効果音が中心。未確認 |

## アプリへの組み込みで注意すること(検索結果。二次情報のため、公式の条項で再確認が必要)
- 「YouTube 向けのロイヤリティフリー」は、**ソフトウェアへの再配布を許可しない**ことが多い。アプリに音楽を入れる場合は、アプリへの埋め込みを明記した契約が必要。
- CC0 は、帰属表示なし・商用可・改変可。ただし、曲ごとに権利者の確認が必要。
