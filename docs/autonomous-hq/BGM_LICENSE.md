# BGM の調査(2026-11-22)

**結論: 商用アプリへの組み込み・完成動画への埋め込み・ユーザーの保存や SNS 投稿までを、個別の曲で確認できた CC0 音源は、まだ無い。購入・採用はしない(オーナー判断待ち)。**

## 確認したことと、していないこと
| 取得元 | 到達 | 結果 |
|---|---|---|
| Free Music Archive | 200 | 「Public Domain」「商用利用」の絞り込みがあるが、曲ごとのライセンスページの確認が必要。JavaScript 中心のページで、個別の曲の確認は未実施 |
| OpenGameArt(CC0・音楽) | 200 | 一覧は取れた(5 Chiptunes、Battle Theme A、Town Theme RPG など)。**ゲーム用のチップチューン・BGM が中心で、Vlog・旅行には合わない**。CC0 は投稿者の申告で、権利の確認は第三者が行っていない |
| archive.org(CC0 表示) | 200 | 投稿者の自己申告で信頼できない(動画で、権利が明らかに CC0 でないものが上位に並んだ)。音楽は、朗読(LibriVox)が上位 |
| Coverr の音楽 | 200 | 動画と同じライセンス。**AI の評価・学習への利用不可**の条項が音楽にも及ぶ(STOCK_DATASET の訂正を参照) |
| Mixkit の音楽 | 200 | 「Stock Music Free License」の本文を取得できなかった。確認できないので採用しない |
| Freesound | 301 | 効果音が中心。未確認 |

## アプリへの組み込みで注意すること(検索結果。二次情報のため、公式の条項で再確認が必要)
- 「YouTube 向けのロイヤリティフリー」は、**ソフトウェアへの再配布を許可しない**ことが多い。アプリに音楽を入れる場合は、アプリへの埋め込みを明記した契約が必要。
- CC0 は、帰属表示なし・商用可・改変可。ただし、曲ごとに権利者の確認が必要。

オーナーの判断に必要な次の調査: 各社の公式の条項で、①アプリへの埋め込み ②利用者の保存・SNS 投稿 ③契約終了後の扱い ④価格を確認する(問い合わせが必要なものあり)。

## 2026-11-22(続き)公式の条項と価格の比較(優先順位: TunePocket → Epidemic Sound → Artlist → Soundstripe)
**注意**: 動画投稿者向けのプランと、アプリ組み込み向けのライセンスは別。下は、アプリ組み込み向けを中心に記録する。購入・契約はしていない。

### 1. TunePocket(公式: tunepocket.com の Licensing Agreement と register-extended)
| 確認項目 | 結果 |
|---|---|
| 動画編集アプリへの組み込み | **可(Extended Business Subscription)**。「ユーザーが新しい動画を作る、アプリが**オンデマンドで**提供する BGM を使う、無料または有料の動画編集・コンテンツ作成ソフト」に使える。**1 つのオンデマンドのアプリまたはサイト、利用者 5 万人まで**。音楽ライブラリ・ダウンロード置き場のようなサービス、ファイルを直接ダウンロードさせる使い方は対象外 |
| 完成動画への埋め込み・保存・SNS 投稿 | **可**。アプリの利用者は、**完成した作品を商用で配布する永続的な権利**を得る(元の音源そのものは対象外)。SNS の投稿・リール・広告は、すべてのプラットフォームで可 |
| 無料・有料ユーザーへの提供 | **可**(「無料または有料の」アプリと明記) |
| 契約終了後 | アプリが音源を利用者に提供している間、**契約を続ける必要がある**。契約が切れたら、アプリで音源を提供できなくなる。**過去に作られた完成動画の扱い**は、「完成した作品の永続的な権利」から、利用者は配信を続けられると読めるが、**アプリが過去の動画を再配信・再生成・再編集できるか**は明記がなく、**書面で確認が必要** |
| **AIによる自動選曲・分析(重要な懸念)** | 契約書に 2 つの条項がある。①「音楽を、AI・機械学習システム・音楽生成ツールなどの、学習・ファインチューン・開発・**改善**、またはデータセットのために使わない。入力・参考資料・プロンプトとして使うことも含む」 ②「音源を、**AI・機械学習・音楽生成・音声生成・データセット・モデル学習・自動コンテンツ作成のサービス(音源を分析・学習・模倣・変換・派生物を作るものを含む)に、使わせない・アップロードしない**」。**AI が自動で選曲するアプリ、および拍の解析(ビート検出)・Sonnet などの外部 LLM に音源や分析結果を送る使い方が、②に当たる可能性があり、書面での確認が必須**。「オンデマンドのアプリ」の許可と、②の「自動コンテンツ作成サービス」の禁止が、どう両立するかが不明 |
| 費用 | Extended Business Subscription **$999.00**(期間の記載はこのページには無い。契約書は年額プランを前提としている → 年額と推定、**要確認**)。比較: Business(通常、アプリ組み込みなし)$199/年、Personal $99/年、Business App Streaming $199(再生専用のアプリ向け。動画を作るアプリは対象外) |
| 動画の作成に使う透かし付きプレビュー | テスト・デモ・評価のみ可 |

### 2. Epidemic Sound(公式: epidemicsound.com の開発者ページと developers.epidemicsound.com)
| 確認項目 | 結果 |
|---|---|
| 動画編集アプリへの組み込み | **可(Partner API)**。動画編集ソフト・AI コンテンツツール・SNS アプリなどが対象 |
| AI による選曲 | **公式に対応**。「Soundmatch」は動画のフレームを分析して、合う曲を推薦する。生成動画のワークフローで、プロンプトや動画から自動でサウンドトラックを作る使い方も明記。「**別の AI のライセンスは不要**」と書かれている |
| 完成動画・保存・SNS | 「ユーザーが公開する分をクリア」「**ユーザーへのサブライセンスに対応**。YouTube・Instagram・TikTok などに対応」 |
| 無料・有料ユーザー | 記載なし(未確認) |
| プランと費用 | **Free: 試作のみ。公開(本番)は不可。ダウンロード 50 件まで、商用ライセンスなし**。**Scale: ダウンロード量に応じた価格(金額は公開されていない)**。商用ライセンス、ユーザーへのサブライセンスあり、月のダウンロード数に上限。**Enterprise: 月 1,000 ダウンロードを超える大きな利用者向け。カスタム。最低契約期間 12 か月**(個人向けのプランページ)。**API の価格は未確認** |
| 契約終了後 | 公式のページには明記なし。**未確認**(第三者の記事では「契約期間のみ有効」の可能性) |
| 注意 | 個人向けの Creator・Pro プラン(月額)は、API・アプリ組み込みとは別のもの。比較に使わない |

### 3. Artlist
公式の API ページ・Enterprise ページに、価格・利用条件の記載なし(「Contact Sales」「Custom license」)。音楽 API の存在は確認できたが、**アプリ組み込み・サブライセンス・契約終了後の扱い・費用はすべて未確認**。問い合わせが必要。

### 4. Soundstripe
公式サイトが、取得時に HTTP 406 で拒否した。ブラウザを装う再取得は、サイトの拒否を避ける操作になるため行わなかった。**すべて未確認**。
