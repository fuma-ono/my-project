# BLOCKERS(障害・未解決の問題)

| ID | 状態 | 内容 | 影響 | 必要な対応 |
|---|---|---|---|---|
| B-1 | 未解決(人間の判断) | 聴感(BGM の大きさの好み、カットの自然さ、発音の欠落、字幕と声のタイミング)を自動では判定できない | 「製品として完成」の最終判定 | オーナーが出力動画を試聴して評価シートに記入する |
| B-2 | 未解決(人間の承認) | DEV のホスティング先が無い。外部に置くには、アカウント作成や費用が発生する可能性がある | DEV 反映は「ローカル起動での確認」で代替している | ホスティング先(無料枠を含む)と公開範囲の決定。本番公開は承認が必要 |
| B-3 | 一部解決 | 課金・決済・アカウント機能が無い | 有料プランを提供できない | 料金仕様 v1 で App Store の定期購読に決定。サーバー側の検証・利用枠・アカウント(端末と appAccountToken)は実装済み。残りは B-7〜B-9 |
| B-4 | 記録のみ | 既存 `bgm-pipeline` の `core.widen` が一部の長さで失敗する | 30秒単位の切り上げで回避中。BGM は内蔵の簡易生成にも切り替わる | bgm-pipeline は変更しない方針。直すかどうかは別途判断 |
| B-5 | 解決済み | 中断した `git fetch` の一時ファイル(約25GB)でディスクが一杯になった | 書き込み不可 | 一時ファイルを削除して回復。以後は必要なブランチだけ fetch |
| B-6 | 未検証 | 実際の長尺(3〜5分以上)の撮影動画、可変フレームレートの素材 | 長尺での処理時間・認識の安定性 | 素材の提供(オーナー)または合成素材での検証の拡大 |
| B-7 | 未解決(環境) | iOS アプリ(SwiftUI・StoreKit 2)は Mac と Xcode が必要で、このクラウド環境(Linux)では作れない・確かめられない | 実装順序 4(iOS の表示)・5(App Store 課金の iOS 側)・7(実機の検証) | Mac での開発環境、または iOS 担当の作業場所。サーバーの API と Web の画面は用意済み |
| B-8 | 未解決(人間の承認・有料) | Apple Developer Program(年会費)、App Store Connect での商品(定期購読)の作成と価格の設定 | 本物の購入・Sandbox での確認ができない | 登録と費用の承認。商品 ID を `config/plans.json` に設定する |
| B-9 | 未解決(人間の承認) | 本番用の Apple のルート証明書の配置、App Store Server Notifications の受け先 URL の公開(本番公開に当たる) | 本番環境での購入の反映・解約・返金の通知 | 本番公開の承認。ルート証明書のファイルを `apple.root_cert_paths` に設定する |
| B-10 | 未解決(取得経路) | 実動画の代わりのテストデータセットが作れていない(取得できた素材は 0 本)。Pexels・Pixabay・Coverr・Mixkit は規約で自動取得が禁止または不明、Wikimedia Commons は規約上は可だが、この環境の共有の出口が配信サーバーに 429 で拒否されている | AI 編集の品質検証(無料版と Sonnet 版の比較)に進めない(最優先) | STOCK_DATASET.md の選択肢(Commons の制限が解けるのを待つ/オーナーが手動で少数をダウンロード/許諾済みの動画の提供) |
| B-11 | 未解決(オーナーの判断) | Sonnet 版の実行に、Claude API キーの登録が必要(環境変数のみ可)。登録は実動画が届いてから | Sonnet 版との比較ができない | API_KEY_SAFETY.md の運用(専用ワークスペース・上限 3 ドル・ワークスペース限定のキー)でキーを登録 |
| B-12 | 未解決 | BGM の音源が未決定。CC0 の候補は根拠を確認したが、取得・測定・試聴・出どころの確認が未了 | 完成動画の仕上がり(BGM)が検証用の自動生成のまま | HIGHLIGHT_ENGINE.md の8章。オーナーの試聴 |
