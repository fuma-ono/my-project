# 恋愛ジャンルnote 記事テンプレート

週次Routineが記事を生成する際、および作家Bが手動で書く際は、このテンプレートに沿う。

## タイトル

読者の悩みを一言で言い切る。**15〜22文字**。

## 導入文

**100〜150文字**。読者の感情に寄り添い、その月のテーマ(`monthly_themes.py`)を提示する。

## 本文(4セクション構成)

1. **現象の説明(共感)** — 「これ、自分だけじゃないんだ」と思わせる、あるあるの描写
2. **心理の正体(理由)** — なぜそう感じるのか、心理的な背景を解説
3. **心の扱い方(解決)** — 明日から実践できる、具体的な向き合い方
4. **未来の姿(希望)** — このテーマを乗り越えた先にある状態を描く

## まとめ(3行)

```
・今日のテーマ: {テーマ}
・感情の正体: {1行で}
・心の扱い方: {1行で}
```

## 次回予告

次回扱うサブテーマを一言で予告し、フォローの動機を作る。

## 表記ルール

- 一人称の相談・エッセイ調(「〜だと思う」「〜かもしれない」)。断定しすぎない
- 実在の個人を特定できる情報(本名・SNS ID・学校名・勤務先など)は書かない・変える
- 医療・法律に関わる助言はしない(必要な場合は専門機関の利用を促すに留める)
- 読者投稿を元にする場合は「投稿を元にしたフィクション/一部再構成」である旨を明記する(`love-note/README.md` の運用ルール参照)
