# セキュリティ規則(VAE)

1. 認証情報・API キー・トークンをコード・ログ・コミット・評価シートに書かない。コミット前フックが代表的な形式を検出して止める
2. ユーザーの動画は個人情報として扱う。アップロード先はジョブごとのフォルダに限定し、期限(既定24時間)で削除する設定を持つ
3. アップロードされたファイル名をそのままパスに使わない(パストラバーサル防止)。拡張子・サイズ・中身(ffprobe)を検証する
4. Web UI は既定で `127.0.0.1` にだけ待ち受ける。外部公開は本番公開に当たるため人間の承認が必要
5. FFmpeg に渡す引数はリストで渡し、シェルを経由しない
6. 動画・音声・文字起こしの全文を Git にコミットしない
