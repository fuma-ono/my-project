# 台本07(スカッと系・LINEチャット形式・若者向け新構成)

**タイトル案**: 「落ちてるぞ」と煽ってきた友達、実は自分が受験すらしてなかったｗｗ

**登場**: 私(主人公、ずんだもん)、友達ゆうと(白上虎太郎)

**グループ名**: ゆうと

**2026-08-20作成(3回目)**: 旧版(共有ノートの消し忘れでカンニング発覚ネタ)を、
オーナー提供の新しい台詞に全面差し替え。台詞は原文のまま、フォーマット
(話者名の統一・sfx配置)のみ既存の台本形式に合わせて整えた。掲示板の
番号を勘違いして煽ってきた友達が、実は自分の番号を思い違えていただけ
でなく、そもそも受験票を忘れて受験自体していなかったという二段オチ。
①誰かが調べて論破するのではなく、本人の勘違い発言が自分で自分を
落とし穴に落とす自爆構造、②ドーンは"それ俺じゃん"と気づいた直後の
決定的な瞬間に、いやっホーは動画の一番最後に、という06〜08で確立した
型を踏襲。
