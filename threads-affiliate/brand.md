# Threadsアフィリエイトアカウント設計

`post-template.md`(共感型/発見型/比較型/まとめ型の4パターン)に合わせた世界観。「特定の商品を売るアカウント」ではなく「暮らしの中で、これ知ってたら便利だったと思える商品・サービスを発掘して紹介するアカウント」(2026-09-09、オーナー指示。`docs/marketing/2026-09-09-threads-account-repositioning.md`)として運用する。

## 表示名

**便利、見つけた。**(2026-09-08、オーナーが変更完了)

理由: 「発見投稿」(こんなのあるの知ってた?)のトーンをそのまま名前にしている。商品広告ではなく、日常の気づきを共有する個人アカウントの体裁を最初から示す。

## ユーザーID

**benri_mitsuketa**

Threadsのユーザー名は日本語不可(英数字・アンダースコアのみ)のため、表示名をローマ字化した。

## プロフィール文(コピペ用)

```
地味に助かる系のもの、見つけたら共有してます。
たまに商品紹介あり(PR表記します)。
```

## 対象ジャンル(2026-09-09、限定を撤廃)

特定ジャンルに絞らない。生活便利グッズ・キッチン用品・家電・スマホ/PC周辺機器・旅行用品・車用品・防災用品・季節商品・美容/身だしなみ用品・収納/掃除用品・AI/Webサービスなど、日常の「これ便利」を幅広く扱う。ただし無差別ではなく「誰かの困りごとを解決する便利なもの」を優先する。詳細は`docs/marketing/2026-09-09-threads-account-repositioning.md`参照(`research.py`の`KEYWORDS`と連動、ただし物販ジャンルのみ自動調査可)。

## 投稿トーンの一貫性

- 4パターン(共感型・発見型・比較型・まとめ型)をローテーションし、アフィリエイト投稿ばかりのアカウントにしない
- 一人称の気づき・発見の口調(「調べてみたら〜らしい」「地味に〜じゃない?」)。売り込み口調は避ける
- アフィリエイトリンクを含む投稿は必ず冒頭に【PR】等の広告表示を入れる(末尾のみは不可)
- 詳細な構成ルールは `post-template.md` 参照
