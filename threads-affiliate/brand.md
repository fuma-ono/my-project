# Threadsアフィリエイトアカウント設計

`post-template.md`(共感/発見/比較/商品紹介/まとめの5パターン)に合わせた世界観。「商品を紹介するアカウント」ではなく「便利な商品・知らなかった商品を教えてくれるアカウント」(`docs/marketing/2026-09-08-threads-post-quality-guidelines.md`の最終目標)として運用する。

## 表示名

**便利、見つけた。**(2026-09-08、オーナーが変更完了)

理由: 「発見投稿」(こんなのあるの知ってた?)のトーンをそのまま名前にしている。商品広告ではなく、日常の気づきを共有する個人アカウントの体裁を最初から示す。

## ユーザーID

**benri_mitsuketa**

Threadsのユーザー名は日本語不可(英数字・アンダースコアのみ)のため、表示名をローマ字化した。

## プロフィール文(コピペ用)

```
地味に助かる系のもの、見つけたら共有してます。
たまに商品紹介あり(PR表記します)。
```

## 対象ジャンル

`docs/marketing/2026-09-08-genre-pivot.md`の基準で選定。モバイルバッテリー・電気ケトル・折りたたみ傘・電気毛布を中心に、対象者を特定の趣味・職業に絞らない広い需要のジャンルを扱う(`research.py`の`KEYWORDS`と連動)。

## 投稿トーンの一貫性

- 「商品紹介」パターン以外(共感・発見・比較・まとめ)も積極的に投稿し、アフィリエイト投稿ばかりのアカウントにしない
- 一人称の気づき・発見の口調(「調べてみたら〜らしい」「地味に〜じゃない?」)。売り込み口調は避ける
- 詳細な構成ルールは `post-template.md` 参照
