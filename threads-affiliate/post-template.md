# Threads投稿 構成テンプレート

`docs/marketing/2026-08-18-ai-affiliate-feasibility.md` の方針に基づく。週次Routineが投稿を生成する際はこれに従う。

## ジャンル

2026-09-08にジャンル方針を見直した(詳細は `docs/marketing/2026-09-08-genre-pivot.md`)。Focus & Sleep事業との親和性ではなく、以下5基準で選定する:

1. 数値・サイズで比較できる(効果・効能を語らなくていい)
2. 型番が変わりにくく、来年も同じ悩みで検索される
3. 検索需要はあるのに、まともな比較記事が少ない
4. 3,000〜15,000円(迷って調べる程度の価格帯)
5. 薬機法・景品表示法リスクが低い

現在の対象ジャンル: モバイルバッテリー・電気ケトル・折りたたみ傘・電気毛布(`research.py`の`KEYWORDS`と連動)。ガジェット全般(型番の陳腐化が速く比較記事も飽和)・美容/金融(規制リスクが高い)は扱わない。

## 使う構成パターン(週替わりでローテーション)

1. **まとめ型**: 「〇〇な人におすすめの3つ」のようなリスト形式
2. **殴り書き型**: 独り言のような口調で、思いついたことをそのまま書いたような体裁(ただし内容は事実に基づく)
3. **悩み解決型**: 「〇〇で困っていませんか」から入り、解決策として商品を紹介
4. **知的好奇心型**: 「なぜ〇〇なのか調べてみた」から入る(note記事の柱Aと同じアプローチ)

## 厳守ルール

- **本文の冒頭または末尾に必ずPR表記を入れる**(例: 「#PR」「#広告」)。景品表示法のステマ規制対応、省略不可
- **使ったことのない商品について「使ってみた」「効果があった」等の断定的な体験談を書かない**。「気になっている」「レビューを見ると〜という声が多い」など、事実に基づく表現に留める
- 医療・健康効果を断定しない(「絶対に眠れる」等の表現は使わない)
- 1投稿1商品を基本とする(複数商品を並べる「リンク集」的な投稿はしない)
- 文字数は**アフィリエイトリンクを含めて**Threadsの制限(500文字)以内(`publish.py`が投稿時に本文末尾へリンクを追記するため、`text`単体の文字数だけでなくリンクの長さも見込んで生成すること)

## 出力フォーマット(`pending/*.json`)

```json
{
  "text": "本文(PR表記込み)",
  "affiliate_link": "https://... (楽天アフィリエイトリンク)",
  "product_name": "商品名(社内管理用、投稿には含めなくてよい)",
  "pattern": "まとめ型|殴り書き型|悩み解決型|知的好奇心型"
}
```
